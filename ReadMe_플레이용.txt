해당 키트를 사용하여 만든 게임을 배포하실 분의 정보 기재란

[v1.5 업데이트] 로컬라이징 추가
- 설정(Esc)의 ‘Language’에서 영어·한국어·일본어·중국어(간체)·중국어(번체)를 고를 수 있습니다. 처음에는 영어로 열립니다.
- 메뉴와 안내 글자가 바뀌며, 대사는 게임을 만든 분이 쓴 언어 그대로 나옵니다.

--------------------------------------------------
1. 게임 실행 방법
--------------------------------------------------

① index.html 파일을 크롬(Chrome)이나 엣지(Edge) 브라우저로 엽니다.
② 시작 안내 화면 오른쪽 아래 ‘폴더 연결’을 누르고 index.html이 들어 있는 폴더를 통째로 선택합니다. (폴더를 시작 화면에 끌어다 놓아도 됩니다.)
③ 로딩이 끝나면 메인 화면이 열립니다. ‘새 게임’을 눌러 시작하세요.

※ 브라우저 보안 정책상 폴더를 한 번 연결해야 대사와 이미지를 읽습니다. (웹에 업로드된 링크로 접속한 경우에는 이 과정이 필요 없습니다.)

--------------------------------------------------
2. 게임 조작법
--------------------------------------------------

스페이스 / 엔터 / 클릭 : 글자 바로 보기, 다음 대사로 넘기기
W / S / ↑ / ↓ : 선택지 이동
스페이스 / 엔터 : 고른 선택지 확정
마우스 클릭 : 선택지 바로 선택
Esc : 설정 열기 / 닫기 (저장하기, 음량 조절, 언어, 엔딩 목록)

--------------------------------------------------
3. 저장 안내 및 문제 해결
--------------------------------------------------

- 저장은 설정(Esc)의 ‘저장하기’를 누를 때만 됩니다. 그 대사 위치와 지금까지 고른 분기가 저장됩니다.
- 엔딩을 봐도 저장한 곳은 그대로 남아서, 선택지 직전에 저장해 두면 엔딩을 본 뒤 ‘불러오기’로 돌아가 다른 선택지를 고를 수 있습니다.
- 저장하지 않은 채 메인 화면으로 가거나 창을 닫으면 마지막 저장 뒤의 진행은 사라집니다. (알림이 뜹니다)
- 저장은 현재 사용 중인 브라우저에만 남습니다. (저장 칸 1개)
- 본 엔딩은 설정의 ‘엔딩 목록’에서 확인하고, 기록을 지울 수 있습니다.
- 소리가 나지 않으면 화면을 한 번 클릭하거나 설정(Esc)에서 음량을 확인해 주세요.
- 언어를 바꿔도 진행 상황은 그대로 유지됩니다.
- 저작권 및 배포 규정은 하단을 확인해주세요.

Information of the person releasing a game made with this kit

[v1.5 update] Localization added
- Choose English, Korean, Japanese, Simplified Chinese or Traditional Chinese with ‘Language’ in Settings (Esc). The game opens in English by default.
- Menus and guide text change; dialogue appears in the language the game’s creator wrote it in.

--------------------------------------------------
1. How to run the game
--------------------------------------------------

① Open index.html in Chrome or Edge.
② On the start guide screen, press ‘Connect Folder’ at the bottom right and select the whole folder that contains index.html. (You can also drag the folder onto the start screen.)
③ When loading finishes, the main screen opens. Press ‘New Game’ to start.

※ Because of browser security rules, the folder must be connected once before the dialogue and images can be read. (This is not needed when you play from an uploaded web link.)

--------------------------------------------------
2. Controls
--------------------------------------------------

Space / Enter / Click : show the whole text, go to the next line
W / S / ↑ / ↓ : move between choices
Space / Enter : confirm the selected choice
Mouse click : pick a choice directly
Esc : open / close Settings (save, volume, language, ending list)

--------------------------------------------------
3. Saving and troubleshooting
--------------------------------------------------

- The game saves only when you press ‘Save’ in Settings (Esc). It saves the current line and the branches you have chosen so far.
- Your save stays even after you see an ending, so if you save right before a choice, you can ‘Load’ after the ending and pick a different choice.
- If you go to the main screen or close the window without saving, progress after your last save is lost. (A warning appears.)
- Saves stay only in the browser you are using. (1 save slot)
- Check the endings you have seen in ‘Ending List’ in Settings, where you can also delete the records.
- If there is no sound, click the screen once or check the volume in Settings (Esc).
- Changing the language keeps your progress.
- See the bottom of this document for copyright and distribution rules.

--------------------------------------------------
1. ゲームの起動方法
--------------------------------------------------

① index.html ファイルを Chrome か Edge ブラウザで開きます。
② スタート案内画面の右下にある「フォルダ接続」を押して、index.html が入っているフォルダをまるごと選びます。(フォルダをスタート画面にドラッグしてもかまいません。)
③ 読み込みが終わるとメイン画面が開きます。「ニューゲーム」を押して始めてください。

※ ブラウザのセキュリティのため、フォルダを一度接続しないと台詞と画像を読み込めません。(ウェブにアップロードされたリンクから遊ぶ場合は必要ありません。)

2. 操作方法
--------------------------------------------------

スペース / エンター / クリック : 文字をすぐ表示、次の台詞へ
W / S / ↑ / ↓ : 選択肢の移動
スペース / エンター : 選んだ選択肢を決定
マウスクリック : 選択肢をすぐ選ぶ
Esc : 設定を開く / 閉じる(セーブ、音量調整、言語、エンディング一覧)

--------------------------------------------------
3. セーブの案内とトラブル解決
--------------------------------------------------

- セーブは設定(Esc)の「セーブ」を押したときだけ行われます。その台詞の位置と、これまで選んだ分岐が保存されます。
- エンディングを見てもセーブした場所はそのまま残るので、選択肢の直前でセーブしておけば、エンディングを見た後「ロード」で戻って別の選択肢を選べます。
- セーブせずにメイン画面へ戻ったりウィンドウを閉じたりすると、最後のセーブ以降の進行は消えます。(お知らせが出ます)
- セーブは今使っているブラウザにだけ残ります。(セーブ枠1つ)
- 見たエンディングは設定の「エンディング一覧」で確認でき、記録を消すこともできます。
- 音が出ないときは、画面を一度クリックするか、設定(Esc)で音量を確認してください。
- 言語を変えても進行状況はそのまま残ります。
- 著作権と配布の規定は下をご確認ください。

- 看完結局後存檔仍會保留，因此如果在選項前存檔，看完結局後可以透過「讀取」回到那裡選擇其他選項。
- 如果不存檔就回到主畫面或關閉視窗，上次存檔之後的進度會遺失。(會出現提示)
- 存檔只保存在目前使用的瀏覽器中。(1 個存檔欄位)
- 已看過的結局可以在設定的「結局列表」中查看，也可以刪除紀錄。
- 如果沒有聲音，請點擊一下畫面，或在設定(Esc)中檢查音量。
- 切換語言後進度保持不變。
